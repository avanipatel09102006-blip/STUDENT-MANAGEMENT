# Student Management System (Flask + SQLite)

    pip install -r requirements.txt
    python app.py
Open http://127.0.0.1:5000

- Add / edit / delete students (enrollment, contact, course, semester, CGPA, attendance)
- Server-side validation (email, ranges, unique enrollment), SQLite `students` table
- Search, course filter, sort, summary cards, students-per-course chart, low-attendance alert
- CSV export (formula-injection safe), responsive table that turns into cards on mobile
- Light, print-friendly theme
